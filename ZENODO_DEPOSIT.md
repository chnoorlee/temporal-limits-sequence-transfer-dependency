# Zenodo / GitHub deposit checklist

1. Edit `CITATION.cff` and `README.md`: replace author TODOs with the final author
   list and affiliations.
2. Create a public GitHub repository (suggested name:
   `temporal-limits-sequence-transfer-dependency`) and push this directory.
3. In GitHub, create a release tag, e.g. `v1.0.0`.
4. Connect the repository to Zenodo (or upload the release ZIP manually), archive
   the release, and copy the DOI.
5. Insert the GitHub URL and DOI in:
   - `README.md`
   - `CITATION.cff`
   - the manuscript Data availability section
   - the cover letter
6. Download the archived files and verify `SHA256SUMS`.
